# Vgen (V_0611) — генератор вертикальных объясняющих роликов

Пайплайн для коротких видео 9:16: **факты → сценарий → фактчек-гейт → озвучка Edge TTS
с word-разметкой → кадры на Skia → пост и kenburns в ffmpeg → mp4 1080×1920**.

Ключевая идея: **каждое событие в кадре привязано к слову диктора**, а не к проценту
таймлайна. Слово ищется в word-boundary разметке Edge TTS, от его времени старта
запускается анимация — картинка не разъезжается с речью при смене голоса или темпа.

## Что нового в V_0611

| Блок | Что сделано |
|---|---|
| **Графика** | `vgen/kit.py` — слой рисования на **Skia**: градиенты, размытие, тени, свечение, текст с обводкой, честный антиалиасинг. Новые рендереры не рисуют плоскими `rectangle`. |
| **Рендереры** | `crane_v2.py` (кран, сцена-хук), `burj_v2.py` (Бурдж-Халифа: 828 м, ступенчатая форма, Y-ядро, вихри) |
| **Движение** | наезд камеры `kenburns` (`zoompan` в ffmpeg), смена планов, дрейф; автогейт `tools/motion_qa.py` |
| **Пост** | bloom + тёплый грейд + хроматика + виньетка + зерно одним проходом ffmpeg |
| **Озвучка** | Edge TTS `ru-RU-SvetlanaNeural`, темп −4%, кэш по фразам (md5), дробление длинных фраз, ретраи — переживает `NoAudioReceived` |
| **Проверка** | `tools/motion_qa.py` (статичные сцены), кадры на временах событий + vision-ревью, фактчек-гейт до рендера |

## Установка

```bash
git clone https://github.com/AliShovk/V_0611.git
cd V_0611
uv venv --python 3.11 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt skia-python   # Windows
# uv pip install --python .venv/bin/python -r requirements.txt skia-python          # Unix
```

Дополнительно:

- **ffmpeg** — подхватывается из `imageio-ffmpeg`; свой бинарник: `FFMPEG=/path/to/ffmpeg`.
- **шрифт с кириллицей** — по умолчанию `msyhbd.ttc` (Windows), `DejaVuSans-Bold` (Linux).
  Свой: `FONT_BOLD=/path/to/font.ttf`.
- **интернет** для Edge TTS (без ключей).
- **Inkscape** (1.2+) — только для старых эпизодов с SVG-слоями.

## Запуск

```bash
.venv/Scripts/python.exe -m vgen.pipeline episodes/burj_wind/project.json
# → out/burj_wind/final.mp4
```

Проверка движения (гейт: score ≥ 1.2 и ≥ 60% «живых» кадров на сцену):

```bash
.venv/Scripts/python.exe tools/motion_qa.py out/burj_wind/final.mp4 out/burj_wind/storyboard.json
```

## Скорость: уложиться в 20 минут

Замер на 4-ядерной машине, ролик 39 с / 1175 кадров:

| Что | Было | Стало |
|---|---|---|
| Рендер кадров | 20–30 мин (1 поток, 0.5–1.5 с/кадр) | **~5 мин** (`ProcessPoolExecutor`, `VGEN_WORKERS`, по умолчанию ядра−1) |
| Сборка | 3 прохода ffmpeg: `silent` → `mixed` → `final` | **1 проход**: кадры + голос + SFX сразу в финал |
| Кодирование | `medium`, crf 19 | `medium`, crf 18 (3 мин 40 с на 39 с видео) |
| **Итого** | 25–35 мин | **~12 мин** |

Как это работает:

- **Кадры параллельно.** План кадров (сцена, кроссфейд, субтитры) считается заранее,
  в воркеры уходят только простые типы; каждый процесс импортирует рендерер один раз
  и держит свой кэш. Число процессов: `VGEN_WORKERS` или `ядра − 1`.
- **Одно кодирование.** Раньше кадры кодировались в `silent.mp4`, потом миксовались
  с озвучкой в `mixed.mp4`, потом прогонялись через пост — три генерации h264.
  Теперь `-framerate 30 -i frames + -i voice.wav + -i sfx.wav` и `filter_complex`
  (пост + `amix`) дают финал за один проход.
- **Дешёвый kenburns.** `zoompan` с `z='min(1+0.0012*on,1.16)'`: зум растёт по номеру
  кадра. С `zoom+0.0006` зум сбрасывался на каждом кадре и движения не было вообще.
- **Не жадничать с пресетом.** `veryfast` + crf 20 на градиентах и зерне даёт
  макроблоки и полосы; `medium` + crf 18 стоит +3 минуты и снимает артефакты.

Ускорять дальше есть куда (в порядке отдачи): отдавать статичные слои в кэш-бэкграунд
на каждый рендерер, считать bloom на полуразрешении, рендерить кадры в PNG-поток
сразу в ffmpeg через pipe вместо диска.

## Пайплайн: восемь стадий

| Стадия | Модуль | Артефакт |
|---|---|---|
| 1. Research | `vgen/stages.py::write_research` | `research.md` |
| 2. Engineering | `stages.engineering` | `engineering.md` |
| 3. Script | `stages.write_script` | `script.md` |
| 4. Fact check (гейт) | `stages.check` | `factcheck.json` |
| 5. Voice | `vgen/voice.py` | `voice.wav`, `subtitles.srt`, `words.json` |
| 6. Storyboard | `vgen/storyboard.py` | `storyboard.json` |
| 7. Animation | `vgen/animation.py` + `renderers/*` | `assets/frames/`, `assets/video_silent.mp4` |
| 8. Edit | `vgen/sfx.py` + ffmpeg | `final.mp4` (1080×1920) |

Плюс `sources.md` — ссылки с датой проверки.

**Гейт фактов.** `stages.check` вытаскивает из сценария все числа (цифрами и словами,
включая составные «двадцать шесть», «полтора») и сверяет с `facts`. Не подтверждено —
пайплайн падает до рендера: `unsupported: [...]`, exit 1.

## Эпизод `project.json`

Обязательные поля: `slug`, `title`, `renderer`, `sources`, `facts`, `script.narration`,
`scenes` (с `anchor` — словом-триггером), `keywords`.

Опционально:

- `post: true` — пост-обработка одним проходом ffmpeg;
- `kenburns: true` — наезд камеры;
- `caption_style: "highlight"` — субтитры с подсветкой ключевых слов.

Эпизоды в репозитории:

- `episodes/burj_wind` — Бурдж-Халифа и ветер (`renderer: "burj_v2"`, Skia);
- `episodes/crane_balance` — кран (`crane`, старая версия; `crane_v2` пока только хук);
- `episodes/lock_panama` — шлюзы Гатун: 26 м, 3 камеры по 8,7 м, вода самотёком;
- `episodes/tbm_city` — тоннелепроходческий щит; `episodes/skyscraper_wind` — небоскрёбы;
- `episodes/ev_range`, `episodes/mouse_sensor`, `episodes/app_close_myth`,
  `episodes/touchscreen`, `episodes/golden_gate` — другие форматы (вектор, пиксель, фото+вектор).

## Правила картинки

- Один источник света на кадр: светлая кромка со стороны света, тень с противоположной.
- Не меньше трёх планов глубины: небо/дальний город, объект, передний план или дымка.
- Объект занимает не меньше половины кадра; пустой тёмный фон с мелким объектом — брак.
- Заголовок до двух строк, кегль ≥ 44 px, нижние ~200 px свободны под субтитры.
- Кадр не стоит: движение объектов + наезд камеры, смена плана каждые 2–3 с.
- **Хук обязателен:** первые 1–2 секунды — парадокс или цифра, без логотипов и «сегодня узнаем».

## Подводные камни (проверено на своих граблях)

- **Edge TTS периодически отдаёт `NoAudioReceived`.** Синтез идёт по фразам с ретраями,
  экспоненциальным бэкоффом и кэшем по md5 — повторный запуск не ждёт сеть.
- **Skia: тысячи `drawRect` — это медленно.** Окна зданий и башни собираются в `skia.Path`
  и рисуются одним вызовом; иначе кадр стоит 1.5 с вместо 0.3.
- **`zoompan` в ffmpeg** дешевле, чем зум в Python: наезд камеры делается на этапе кодирования.
- **Inkscape медленный на блюр-фильтрах**: простой слой ~3 с, сцена с `feGaussianBlur` ~12 с.
  Растеризуйте один раз, анимируйте PNG.
- **PIL не принимает float в `alpha_composite`** — координаты приводите к `int`.
- **`ffmpeg -f concat`** ищет файлы относительно списка — в списке только имена файлов.
- **Python-файлы в этом репозитории — LF.** Правки многострочных блоков по строкам с `\r\n`
  молча не применяются: нормализуйте файл, потом патчите, и проверяйте результат grep'ом.
- **`smax/smin` требуют параметр сглаживания `k`** — забытый аргумент падает только на кадре.
