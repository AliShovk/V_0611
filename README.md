# Vgen — генератор вертикальных объясняющих роликов

Пайплайн для коротких видео 9:16 (Shorts/Reels): **SVG-арт → Inkscape → анимация в PIL → озвучка Edge TTS с посимвольной синхронизацией → субтитры фразами → синтезированный звуковой дизайн → mp4**.

Ключевая идея: **каждое событие в кадре привязано к конкретному слову диктора**, а не к проценту таймлайна. Слово найдено в word-boundary разметке Edge TTS → берётся его время старта → от него запускается анимация. Поэтому картинка не разъезжается с речью при смене голоса или темпа.

## Что умеет

| Возможность | Где смотреть |
|---|---|
| Разрез среды, погружение, слои (Марианская впадина) | `scripts/cartoon_mariana.py` |
| Разрез Земли, буровой снаряд, врезка-лупа | `scripts/cartoon_inner_ocean.py` |
| Процедурная сеть (грибница, корни, гифы) | `scripts/cartoon_mycelium.py` |
| Ледяной щит, керновый бур, подледниковое озеро | `scripts/cartoon_vostok.py` |
| Мультяшный «заражённый» объект, рост паразита из тела | `scripts/cartoon_cordyceps.py` |
| Космос, планеты, счётчики, ответ в финале | `scripts/cartoon_venus.py`, `scripts/cartoon_venus_hook.py` |
| Удар, вспышка, ударные волны, синхронизация по словам | `scripts/cartoon_lightning.py` |
| Синтез SFX и подмешивание к озвучке | `scripts/sfx.py` |
| Общая библиотека (TTS, субтитры, плашки, персонаж) | `scripts/cartoon_engine.py` |

## Установка

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

Нужно ещё:

- **Inkscape** (1.2+) — растеризация SVG-арта. Windows: `C:\Program Files\Inkscape\bin\inkscape.exe`, Linux: `inkscape` в PATH.
- **ffmpeg** — берётся из пакета `imageio-ffmpeg` автоматически. Свой бинарник можно указать переменной `FFMPEG=/path/to/ffmpeg`.
- **шрифт с кириллицей** — по умолчанию ищется `msyhbd.ttc` (Windows), `DejaVuSans-Bold` (Linux), `Arial Bold` (macOS). Свой: `FONT_BOLD=/path/to/font.ttf`.
- **интернет** для Edge TTS (бесплатный, без ключей).

## Быстрый старт

```bash
python scripts/cartoon_venus_hook.py
# -> storage/cartoon-venus-hook/final.mp4  (720x1280, 30 fps, ~31 c)
```

Любой эпизод запускается так же: `python scripts/cartoon_<тема>.py`. Готовое видео кладётся в `storage/<эпизод>/final.mp4`, кадры — в `storage/<эпизод>/frames/`.

## Пайплайн эпизода

1. **Арт в SVG** (`art/*.svg`). Слои раздельные: фон, объект, растущий элемент, оверлей раны.
2. **Экспорт в PNG 2×** через Inkscape:
   ```bash
   tools/export_art.sh          # или вручную:
   inkscape --export-type=png --export-filename=art/bg.png --export-width=1440 art/bg.svg
   ```
3. **Озвучка**: `synthesize(text, out_dir)` — Edge TTS по предложениям, с ретраями, кэшем (`voice.mp3` + `marks.json`) и word-boundary разметкой. Повторный запуск берёт кэш: `load_or_synthesize(text, out_dir)`.
4. **События по словам**:
   ```python
   ev = {
       "temp": word_time(marks, "четырёхсот", total * 0.6),
       "answer": word_time(marks, "венера", total * 0.95),
   }
   ```
5. **Кадры**: `draw(t)` — чистая функция времени, рисует состояние на момент `t` поверх готовых PNG-слоёв.
6. **Субтитры**: `phrase_cues(marks, TEXT)` — фразы по 2–3 слова, границы только по запятым и точкам, `draw_caption()` внизу кадра.
7. **Звук**: `sfx.build_track(total, [(time, "boom", 0.5), ...])` синтезирует удары/вжухи/тинты; `sfx.mix()` подмешивает их к озвучке без перекодирования видео.
8. **Энкод**: `ffmpeg -framerate 30 -i frames/f%05d.png -i voice.mp3 -c:v libx264 -crf 20`.

## Правила, которые вытащены из аналитики YouTube

- **Хук в первую секунду.** Крупный вопрос поверх кадра с 0-й секунды (`cartoon_venus_hook.py`), а не статичный пейзаж.
- **Вопрос в начале — ответ в конце.** Зритель досматривает, чтобы узнать развязку.
- **Название и теги** — по-русски и с интригой, не `cartoon_xxx_final`: «Сутки длиннее года?», «Молния в 5 раз горячее Солнца».
- **Звуковые акценты** на появление плашек держат внимание при минималистичной графике.
- Плашки не должны перекрывать друг друга и уезжать за кадр — проверяйте кадры на событиях (`ffmpeg -ss <t> -frames:v 1`).

## Как сделать новый эпизод

1. Нарисуйте 2–4 SVG-слоя в `art/`, экспортируйте в PNG 2×.
2. Скопируйте ближайший эпизод как шаблон (например, `cartoon_venus_hook.py`).
3. Напишите текст: 60–80 слов, первый абзац — хук, последний — развязка.
4. Найдите в тексте 5–8 слов-триггеров и заведите на них `word_time`.
5. Нарисуйте `draw(t)` от этих времён; всё, что появляется, должно иметь свой SFX.
6. Запустите, выберите 5–6 кадров на временах событий и проверьте их глазами (или через vision-модель).

## Подводные камни (проверено на своих граблях)

- **Edge TTS периодически отдаёт `NoAudioReceived`.** Поэтому синтез идёт по предложениям с 12 ретраями и кэшем; повторный запуск не ждёт сеть.
- **Piper на Windows не умеет писать WAV в stdout** — только в файл (`-f`). Для русского лучше Edge: пипер звучит механически.
- **Inkscape медленный на блюр-фильтрах**: простой слой ~3 с, сцена с `feGaussianBlur` ~12 с. Растеризуйте один раз, анимируйте PNG.
- **PIL не принимает float в `alpha_composite`** — координаты вставки приводите к `int`, иначе `TypeError: 'float' object cannot be interpreted as an integer`.
- **Z-order рассказывает историю**: растущий стебель рисуется *до* объекта (выходит изнутри), оверлей раны — *после* (разрыв на поверхности).
- **Субтитры по одному слову читаются как мусор** — группируйте по 2–3 слова, снимайте конечную пунктуацию.
- **`ffmpeg -f concat`** ищет файлы относительно списка — пишите в список только имена файлов.

## Структура

```
art/                 SVG-исходники и отрендеренные PNG (2×)
scripts/
  cartoon_engine.py  TTS, субтитры, плашки, персонаж, шрифты, ffmpeg
  sfx.py             синтез звуковых эффектов и микс
  cartoon_*.py       эпизоды
tools/
  export_art.sh      пакетный экспорт SVG -> PNG через Inkscape
storage/<эпизод>/    voice.mp3, marks.json, frames/, final.mp4
```
